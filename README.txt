Bosla AI — Website package
==========================

FILES
-----
index.html        الموقع الكامل (صفحة واحدة — كل حاجة فيه)
robots.txt        لتعليمات محركات البحث
sitemap.xml       خريطة الموقع
site.webmanifest  إعدادات PWA (يخلي الموقع يتثبت كتطبيق على الموبايل)
og-cover.png      صورة المشاركة لما حد يبعت اللينك على واتساب/فيسبوك
icon-192/512.png  أيقونات التطبيق

BEFORE LAUNCH — عدّل دول
-------------------------
1) رقم الواتساب: في أول سكربت داخل index.html غيّر
   var WHATSAPP_NUMBER = "201000000000";
   لرقمك بالصيغة الدولية (2 + كود مصر 10 + الرقم بدون الصفر)
   الرقم ده بيتحكم في: الفورم، زر واتساب العائم، وسكيما جوجل.

2) الدومين: استبدل bosla-ai.com ب دومينك الحقيقي في:
   canonical + Open Graph (أعلى index.html) + robots.txt + sitemap.xml

3) الإيميل ورقم التليفون في الفوتر (ابحث عن hello@bosla-ai.com و +20 100 000 0000)

4) روابط السوشيال: الفوتر فيها 4 أيقونات href="#" — حط لينكاتك

5) تحليلات جوجل: في آخر index.html فيه كود Google Analytics
   متعلّق — غيّر G-XXXXXXXXXX بـ ID بتاعك وشيل علامات التعليق

6) الصور: لو عايز صور حقيقية للأيقونات، استبدل ملفات icon-*.png
   بنفس المقاسات واحتفظ بنفس الأسماء

DEPLOY (مجاني وسريع)
--------------------
- Netlify / Vercel: اسحب ملفات الفولدر كلها — خلاص
- GitHub Pages: ارفع على repo وفعّل Pages
- استضافة عادية (cPanel): ارفع الملفات لمجلد public_html

NOTE
----
الأسعار والشهادات (آراء العملاء والإحصائيات) أرقام توضيحية —
عدّلها بالأرقام الحقيقية قبل النشر.
